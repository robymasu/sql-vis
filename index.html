3. AI provider

Your API key is used directly from this browser to call the provider's API — SQL-Vis has no backend, so there is no proxy in between. The key stays in memory for this page session only (never written to disk), but it will be visible in this tab's Network panel like any client-only app that calls an API directly.

This uses a shared team key held server-side (Vercel) — your browser never sees the real API key, only the password gates access to it. Only works once this app is actually deployed (Vercel, or vercel dev) — a plain static server like npx serve has no backend to call, see api/rewrite.js.

4. Test tables (optional)

If you validate by materializing full test tables in a scratch/playground schema — rather than diffing the raw old/new source directly — name them here. SQL-Vis will generate two ready-to-run "CREATE OR REPLACE TABLE" statements (the untouched original query, and the AI-rewritten one) plus a comparison query that diffs those two tables' own output instead of the raw source. Leave both blank to get the raw-source comparison query instead.

Required for this CTE target: a CTE can't be queried standalone the way a physical table can, so the raw-source comparison isn't available here — name both test tables below.
